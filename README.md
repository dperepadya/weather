# Flask Weather Application

This is a simple Flask web application that allows users to enter a location and get the current weather data for that location using the OpenWeatherMap API. The application also displays the location on a Google Map.

## Features

- **Location Input:** Users can input any location (city, region, country) to retrieve weather data.
- **Weather Data:** Displays current temperature, wind speed, and precipitation for the specified location.
- **Google Maps Integration:** Shows the location on a Google Map.

## Prerequisites

Before you begin, ensure you have the following:

- Python 3.x installed
- Flask library
- Requests library
- Access to OpenWeatherMap and Google Maps APIs
